# REST API

## Overview
REST API stands for **Representational State Transfer API**.  
It is a type of **Application Programming Interface (API)** that allows communication between different systems over the internet.

REST APIs follow a **request–response model**, and data is typically exchanged in **JSON format**.

---

## HTTP Methods

REST APIs commonly use the following HTTP methods:

### GET
- Used to request (read) data from the server.

### POST
- Used to send data to the server.

### PUT
- Used to update or create a resource on the server.

### PATCH
- Used to update specific fields of a resource on the server.

### DELETE
- Used to delete a resource from the server.

---

## HTTP Status Codes

In REST APIs, HTTP status codes indicate the result of a request.

### 2xx – Success
- Request completed successfully.

### 3xx – Redirection
- Request requires redirection.

### 4xx – Client Error
- Error caused by the client (unauthorized, not found, etc.).

### 5xx – Server Error
- Error occurred on the server side.
